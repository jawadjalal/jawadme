# Loader A: the words

The board streams these words, one whole word at a time, each set as a shaped run in Noto Kufi Arabic. Jawad checks the
meaning before anything ships.

| Arabic | Transliteration | English |
|---|---|---|
| صنعة | ṣanʿa | craft, workmanship |
| نور | nūr | light |
| بناء | bināʾ | building, construction |
| خط | khaṭṭ | line; also calligraphy, handwriting |
| فكرة | fikra | idea |
| حبر | ḥibr | ink |
| شكل | shakl | form, shape |
| ابتكار | ibtikār | invention, innovation |

## Where the board halts

| Arabic | Transliteration | English |
|---|---|---|
| تصميم | taṣmīm | design |
| عقل مدبر | ʿaql mudabbir | mastermind (literally "a planning mind", the mind behind a plan) |

The first row ("design") halts on تصميم while the second keeps searching, then seats on عقل مدبر, so for a beat the board
reads the mark in Arabic before it locks into "design mastermind". عقل مدبر is written without the shadda (مدبّر), as it
usually is in running text.
